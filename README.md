# Practice Room

A guitar practice room: a clickable fretboard, scales and modes with highlighted tonics and relative tonics, mode maps, scale runs, arpeggios in position, sweep arpeggios with each mode's color note, a bell metronome (0-100 BPM) and a soft background keys track that follows chord progressions.

**Course:** 37 lessons of scales and arpeggios in five tracks (Blues, Rock, Jazz, Fusion, Country). Each lesson loads its scale, position, exercise, tempo and backing chords on the fretboard.

**Open:** https://espartabranding.github.io/vai-practice-room/

Non-commercial project. All theory texts and sounds were written and synthesized for this page.
