# Vai Practice Room

A guitar practice room under the Eye of Providence: a clickable fretboard, scales and modes with golden tonics and relative tonics, mode maps, scale runs, sweep arpeggios with each mode's color note, a bell metronome (0-100 BPM) and a soft background keys track.

**Open:** https://espartabranding.github.io/vai-practice-room/

Fan project, non-commercial, inspired by Steve Vai. Steve Vai's name and logo belong to their owner. All theory texts and sounds were written and synthesized for this page.
